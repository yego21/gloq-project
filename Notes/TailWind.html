⚡ Tailwind CLI Quick Reference

Your complete guide to Tailwind standalone binary with Django

Essential Commands

Development (Watch Mode)

./tailwindcss -i ./static/src/input.css -o ./static/css/output.css --watch
  • Watches for file changes and rebuilds automatically
  • Keep this running while developing
  • Start it once, leave it running

Production Build

./tailwindcss -i ./static/src/input.css -o ./static/css/output.css --minify
  • Generates optimized, minified CSS
  • Run before deploying
  • Creates smallest possible file size

One-Time Build (Testing)

./tailwindcss -i ./static/src/input.css -o ./static/css/output.css
  • Builds once and exits
  • No watching, no minification
  • Good for quick tests

File Structure

your_django_project/ ├── manage.py ├── tailwindcss # Standalone binary ├── static/ │ ├── src/ │ │ └── input.css # Source CSS with @import │ └── css/ │ └── output.css # Generated (don't commit) └── templates/ └── base.html

Input CSS File

static/src/input.css

@import "tailwindcss";

@source "../../templates";
@source "../../*/templates";

@theme {
  /* Custom theme here */
}

Django Template Usage

<%load static %>
<!DOCTYPE html>
<html>
<head>
    <link href="<%static 'css/output.css' %>" rel="stylesheet">
</head>
<body>
    <!-- Your Tailwind classes here -->
</body>
</html>

Daily Workflow

Terminal 1: Tailwind Watch

./tailwindcss -i ./static/src/input.css -o ./static/css/output.css --watch

Terminal 2: Django Server

python manage.py runserver
💡 Tip: Keep both terminals running while developing!

Common Flags

  • -i or --input - Input CSS file
  • -o or --output - Output CSS file
  • -w or --watch - Watch mode
  • -m or --minify - Minify output
  • --optimize - Optimize without minifying
  • -h or --help - Show all options

Deployment Script

#!/bin/bash
./tailwindcss -i ./static/src/input.css -o ./static/css/output.css --minify
python manage.py collectstatic --noinput

Important Notes

⚠️ Remember:
  • Watch mode stays running - don't restart after every change
  • Production builds should use --minify flag
  • Add static/css/output.css to .gitignore
  • Tailwind scans for complete class names only (no dynamic classes)

Troubleshooting

🔴 Styles not updating?

  • Make sure watch mode is running
  • Check console for Tailwind rebuild messages
  • Try hard refresh (Ctrl+Shift+R)

🔴 Classes not working?

  • Verify @source paths in input.css
  • Make sure class names are complete (not dynamic)
  • Check that output.css was generated

🔴 File not found errors?

  • Confirm STATICFILES_DIRS in settings.py
  • Run python manage.py collectstatic for production
