🐳 Docker Commands Quick Reference

Essential Docker commands for Django development

Basic Docker Commands

Build Image

docker build -t myapp .
Build an image from Dockerfile in current directory with tag "myapp"
docker build -t myapp:v1.0 .
Build with specific version tag
docker build --no-cache -t myapp .
Build without using cache (fresh build)

Run Container

docker run --env-file .env -p 8000:8000 myapp
Run container with environment file, mapping port 8000
docker run -d --env-file .env -p 8000:8000 myapp
Run in detached mode (background)
docker run -it --rm myapp /bin/bash
Run interactively with bash shell, remove after exit

List & Inspect

docker ps
List running containers
docker ps -a
List all containers (including stopped)
docker images
List all images
docker logs <container-id>
View container logs
docker logs -f <container-id>
Follow logs in real-time

Execute Commands in Container

docker exec <container-id> ls -la /app/static/css/
Run a command in running container
docker exec -it <container-id> /bin/bash
Open interactive shell in running container
docker exec <container-id> python manage.py migrate
Run Django management command

Stop & Remove

docker stop <container-id>
Stop a running container
docker rm <container-id>
Remove a stopped container
docker rmi <image-id>
Remove an image
docker system prune -a
Remove all unused containers, images, and networks

Docker Compose Commands

Basic Operations

docker-compose up
Start all services defined in docker-compose.yml
docker-compose up -d
Start services in detached mode (background)
docker-compose up --build
Rebuild images and start services
docker-compose down
Stop and remove all containers
docker-compose down -v
Stop containers and remove volumes

Build & Rebuild

docker-compose build
Build or rebuild services
docker-compose build --no-cache
Build without using cache

Logs & Status

docker-compose logs
View logs from all services
docker-compose logs -f web
Follow logs for specific service (e.g., web)
docker-compose ps
List containers
docker-compose ps -a
List all containers (including stopped)

Execute Commands

docker-compose exec web ls -la static/css/
Execute command in running service
docker-compose exec web python manage.py migrate
Run Django migrations
docker-compose exec web python manage.py createsuperuser
Create Django superuser

Restart Services

docker-compose restart
Restart all services
docker-compose restart web
Restart specific service

Common Workflows

🔨 Development Workflow

# Build and start docker-compose up --build # View logs docker-compose logs -f # Stop Ctrl+C or docker-compose down

🔄 Rebuild After Changes

# Stop services docker-compose down # Rebuild docker-compose build --no-cache # Start again docker-compose up

Debugging Commands

# Check if container is running docker ps # View container logs docker logs <container-id> # Enter container shell docker exec -it <container-id> /bin/bash # Check files in container docker exec <container-id> ls -la /app/ # Check environment variables docker exec <container-id> env

Django-Specific Commands

# Run migrations docker-compose exec web python manage.py migrate # Create superuser docker-compose exec web python manage.py createsuperuser # Collect static files docker-compose exec web python manage.py collectstatic --noinput # Open Django shell docker-compose exec web python manage.py shell # Check installed packages docker-compose exec web pip list

Useful Flags & Options

Flag Description
-d Detached mode (run in background)
-p Publish port (e.g., -p 8000:8000)
--env-file Specify environment file
-it Interactive terminal
--rm Remove container after exit
-v Mount volume (e.g., -v ./app:/app)
--build Build images before starting
--no-cache Build without using cache
-f Follow logs in real-time

Important Notes

💡 Tip: Use docker-compose for multi-container apps (web + database). Use plain docker for single containers.
⚠️ Note: Container IDs can be partial - just use the first few characters (e.g., abc123 instead of full ID).
🔴 Warning: docker system prune -a removes ALL unused images and containers. Use with caution!
💡 Quick Find Container ID:
docker ps # Copy the first 3-4 characters of CONTAINER ID

Our Project Commands

Standard Build & Run

# Build image docker build -t myapp . # Run with env file docker run --env-file .env -p 8000:8000 myapp

With Docker Compose

# Start everything docker-compose up --build # Run in background docker-compose up -d # View logs docker-compose logs -f web # Stop everything docker-compose down

Debugging Static Files

# Check if CSS exists docker exec <container-id> ls -la /app/static/css/ # Check collected static files docker exec <container-id> ls -la /app/staticfiles/ # View file content docker exec <container-id> cat /app/static/css/output.css | head -20 # Check environment variables docker exec <container-id> env | grep -i static

Troubleshooting Commands

Container Won't Start

# Check logs docker logs <container-id> # Or with docker-compose docker-compose logs web # Check if port is already in use netstat -ano | findstr :8000 # Windows lsof -i :8000 # Mac/Linux

Changes Not Reflecting

# Rebuild without cache docker-compose down docker-compose build --no-cache docker-compose up

Database Connection Issues

# Check if database container is running docker-compose ps # Check database logs docker-compose logs db # Test connection from web container docker-compose exec web python manage.py dbshell
